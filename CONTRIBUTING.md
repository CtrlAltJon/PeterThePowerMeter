# Contributing to PeterThePowerMeter

Thank you for your interest in contributing to **PeterThePowerMeter**! We welcome all contributions, whether it's reporting a bug, improving the documentation, or proposing new features.

To ensure a smooth experience for everyone, please follow these guidelines.

## How to contribute

### Reporting Bugs
If you find a bug, please check the [Issues](https://github.com/CtrlAltJon/PeterThePowerMeter/issues) tab to see if it has already been reported. If not, please open a new issue using the **Bug Report** template.

### Proposing Features
Have an idea for a new feature? Open an issue using the **Feature Request** template. We will discuss its feasibility, especially concerning hardware limitations and safety.

### Pull Requests (PRs)
If you want to submit code or hardware improvements:
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/AmazingNewFeature`).
3. Make your changes.
4. Ensure your code follows the existing style and is well-documented.
5. Submit a Pull Request.

**Important:** Please ensure your PR includes a clear description of the changes. If you are modifying hardware-related logic, explain how you have tested it.

## Safety First
Since this project involves interaction with high-voltage (230VAC) mains power:
* **Safety is our top priority.** Never suggest or implement changes that could compromise the electrical safety of the device.
* If you are proposing hardware changes, please include updated wiring diagrams or schematics.
* Always warn others about the dangers of working with mains electricity.

## Code of Conduct
Please note that this project is released with a [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.
