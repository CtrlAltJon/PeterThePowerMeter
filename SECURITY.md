## Reporting Vulnerabilities

Security is a top priority for **PeterThePowerMeter**. Because this project interacts with electrical systems (230VAC), vulnerabilities may present not only software risks but also physical safety risks.

Please do not report security vulnerabilities in public GitHub issues, as this could expose users to potential exploitation or safety hazards.

### How to report a security vulnerability

The best way to report a security issue is to use the **GitHub Security Advisory** feature:

1. Go to the [Security tab](https://github.com/CtrlAltJon/PeterThePowerMeter/security) of this repository.
2. Click on **"Report a vulnerability"**.
3. Follow the steps to create a private report.

This ensures that the report remains confidential between you and me (the project maintainer) until we have analyzed the issue and determined a fix.
